2.Password Generator

  • 1.What does the tool do?

    • The password generator is a sci-fi themed web application that generates highly secure, randomized passwords based on customizable parameters. It mitigates the critical vulnerabilities associated with weak or reused credentials, helping users protect their digital infrastructure against unauthorized access and security breaches.

  • 2. Why I built it:

    • This project was born out of a real-world cybersecurity incident. After my computer was infected with a Trojan virus, hackers exploited my reused passwords to compromise several of my social media and Google accounts. That experience taught me the hard way that credential redundancy is a massive vulnerability. I built this tool not only to deen my proficiency in JavaScript logic and DOM manipulation but to engineer a practical, visually engaging solution to a security problem I had personally suffered from.

  • 3. How it works:

    • For the user:
      The user interacts with a customer slider to define the exact character length of their password (ranging from 8 to 64 characters). They then toggle specific parameters, such as uppercase letters, numbers, and special symbols, using responsive checkboxes. Upon executing the “Generate” command, the application instantly outputs a complex string, which the user can immediately copy to their clipboard for frictionless deployment.

    • Technical:
      1. The Character Groups (The Ingredients): In JavaScript, I had to define raw materials. I created strings of characters:
        • lowercase = "abcdefghijklmnopqrstuvwxyz" (Default base)
        • uppercase = "ABCDEFGHIJKLMNOPQRSTUVWXYZ”
        • numbers = "0123456789”
        • symbols = "!@#$%^&*()_+”
      2. Building the Logic: When the user clicks “Generate”, the code doesn’t just guess. It first looks at the checkboxes (DOM):
        • If the user checked the “Numbers” box, JavaScript takes the lowercase base and glues the “numbers” string onto it.
        • If they checked “Symbols”, it glues those on, too. This created the custom group of allowed characters.
      3. The Randomizer Loop (The Engine): The code looks at the slider. It runs a for loop exactly the number of times the slider is at. Inside the loop, there’s a math function—specifically Math.random() multiplied by the selected length of the password—to blindly reach into the strings of characters and pull out a single random letter, number, or symbol.
      4. Password Assembly: Every time the loop pulls a random character, it attaches it to an empty string(e.g., let = newPassword = “”). After the loop finished the number of times the slider was selected to, that string held the final password, and I pushed it to the HTML using “value”.
      5. The Copy Button: To make the “Copy” button work, I had to tap into the browser’s internal system using navigator.clipboard.writeText(password). This allowed the user to click an icon and instantly paste the password into their accounts

  • 4. Technical Challenges:

    1. Linking the Visual Range Slider: 
      // Getting the input and span tags with the DOM
const lengthSlider = document.getElementById('password-length'); // Range Input
const lengthDisplay = document.getElementById('length-display'); //Span tag to show the number

// Listen for an input
lengthSlider.addEventListener("input", ()=>{ // Execute this function every time the slider moves
lengthDisplay.textContent = lengthSlider.value; // Update the span tag with the current value of the slider
})
      A key UX challenge was ensuring the visual length counter updated simultaneously as the user dragged the range slider. I solved this by capturing the input element via the DOM and attaching an input even listener. This allowed JavaScript to continuously read the slider’s current value property and dynamically inject it into the HTML text display, creating a seamless, real-time feedback for the user.
    2. Combining Characters Based on Which Checkboxes Were Ticked: 
      
function generateKey(){ // We create the function that will run when the user clicks the “Generate” button
const lowercaseChars = "abcdefghijklmnopqrstuvwxyz"; //Set of lowercase characters (Default base)
const uppercaseChars = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"; //Set of uppercase characters
const numberChars = "0123456789"; //Set of number characters
const symbolChars = "!@#$%^&*()_+~`|}{[]:;?><,./-="; //Set of symbol characters

let allowedChars = lowercaseChars; // Declare a variable that will hold the final group of allowed characters. It starts with lowercase as the default base

if(document.getElementById("inc-uppercase").checked){ // If the user checked the “Include Uppercase” box, we glue the uppercase string onto the allowed characters variable
    allowedChars += uppercaseChars;
}
if(document.getElementById("inc-numbers").checked){ // If the user checked the “Include Numbers” box, we glue the numbers string onto the allowed characters variable
    allowedChars += numberChars;
}
if(document.getElementById("inc-symbols").checked){ // If the user checked the “Include Symbols” box, we glue the symbols string onto the allowed characters variable
    allowedChars += symbolChars;
}

let finalKey = ""; // We declare an empty string variable that will hold the final password as we build it

console.log("Allowed characters: " + allowedChars); // Confirmation that the allowed characters variable is correctly building based on which boxes the user checked

const passwordLength = document.getElementById("password-length").value; // Then we capture the value of the slider to know how many times to run the loop

for(let i = 0; i < passwordLength; i++){
// We run a loop as many times as the number selected on the slider. 
// Each time the loop runs, it will pull a random character from the allowed 
// characters variable and glue it to the final key variable
    let randomIndex = Math.floor(Math.random() * allowedChars.length);
    finalKey += allowedChars[randomIndex];
}
// We inject the final key into the HTML using “value”
document.getElementById('password-output').value = finalKey; 
}
      The password generator needed to adapt instantly to user preferences. I managed this by selecting the DOM checkboxes and evaluating their checked boolean properties using if statements. If a parameter was true, its specific character set (e.g., symbols or numbers) was dynamically grouped into the allowed characters string, which served as the raw data group for the randomization algorithm.

  • 5. What I learned:

    1. Event-Driven Programming: By linking the visual range slider to the numerical display, I gained a deep understanding of the DOM and event listeners. I learned how to make a user interface react in real-time to continuous physical inputs (like dragging a slider), rather than just waiting for a button click.
    2. Randomization: I learned the difference between static, hardcoded HTML and dynamic JavaScript. By utilizing for loops and Math.random() I learned how to generate highly unpredictable, secure passwords on the fly, proving to myself that I could write code that creates a unique outcome every time it runs.
    3. State Management: I learned how to manage the state of the application by writing code that constantly checked which parameters boxes the user had ticked (True/False). This taught me how to selectively stitch together different text strings (like combining the alphabet string with the symbols string) in real-time to build a custom group of allowed characters.
