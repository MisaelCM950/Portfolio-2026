1.MISA Chat Bot

  • 1.What does the tool do?

    Misa is a sci-fi themed AI assistant featuring a custom, futuristic persona. It’s designed to assist users with daily tasks while providing an immersive, interactive narrative experience.

  • 2. Why I built it:

    I built Misa to bridge the gap between front-end and design and back-end logic. My primary goals were to learn how to connect a web application to a third-party AI API (OpenAI), understand how to secure sensitive credentials, and practice integrating dynamic AI features into a project. I also wanted to push my HTML, CSS and JavaScript skills by building a complex, real-time chat interface.

  • 3. How it works:

    • For the user:
      Users interact with Misa through a custom chat window. They can type messages to trigger an audio-visual response, engaging in complex conversations powered by the gpt-4o-mini model.
    • Technical:
      The front-end captures the user’s input and sends it to a secure Netlify Serverless Function. This back-end server secretly injects the current date and Misa’s system “prompt” before securely passing the request to OpenAI. The AI’s response is sent back to the front-end, where JavaScript dynamically generates new HTML div elements and injects them into the DOM to display the conversation.

    3. API Security & Server Migration: I initially hosted the site on GitHub pages but quickly learned about automated scraper bots that steal exposed API keys. I had to migrate my architecture to Netlify to utilize a secure back-end environment, storing my OpenAI key safely in an Environment Variable.

  • 5. What I learned:

    1. Client vs. Server Architecture: I gained a deep understanding of the difference between front-end (what the user sees) and back-end (where secrets are kept). I now know how to secure an application against cyber attacks using environment variables.
    2. Cloud Infrastructure:I learned the physical reality of the internet—that the “cloud” consists of massive data centers running enterprise-grade “pizza-box” servers with specialized RAM, designed to run 24/7 for decades.
    3. Advanced JavaScript:I leveled up my JavaScript skills by mastering DOM injection, handling asynchronous API fetch request, and manipulating media.
    4. Asynchronous Programming:I mastered the use of async and await to handle blocking API requests. This allows the application to communicate with external servers in the background without freezing the User Interface, ensuring a fluid and professional 'real-time' experience.
    5. Prompt Engineering & AI Integration:I learned how to architect a master “System Prompt” to give an AI a distinct personality, constraints, and lore. I also learned how to dynamically inject JavaScript date objects into the prompt to fix AI time hallucinations.
    6. Mobile Layout and CSS Flexbox:I overcame complex mobile responsiveness bugs, learning how to manage viewport height(dvh), prevent iOS auto-zooming when clicking the input box, and structure flexbox columns for a native app-like behavior.
